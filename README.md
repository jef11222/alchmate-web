# AlchMate Web 🪙

The official cloud-powered companion dashboard for **Old School RuneScape** High Alchemy, Production Crafting, and Bond Progression.

---

## Features

- **Live High Alchemy Margins:** Real-time prices from the OSRS Wiki Prices API for all 3,500+ items, with instant profit-per-cast, hourly profit (1,200 casts/hr), and ROI tracking.
- **229 Production & Crafting Recipes:** Comprehensive calculators for Potions & Unfinished Herbs, Battlestaves, Dragonhide Crafting, Glassblowing, Smithing, and Lunar Magic.
- **Old School Bond Roadmap:** Live progress bar tracking your total liquid wealth against real-time Bond GE prices.
- **RuneLite Cloud Sync:** Secure, privacy-first webhook API (`/api/sync`) linking the official RuneLite in-game plugin.
- **Zero-Maintenance Database:** Auto-cleaning rolling data retention keeping database storage lean and fast.

---

## Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS (OSRS Dark Theme)
- **Database & Auth:** Supabase (PostgreSQL + Row-Level Security)
- **Hosting:** Vercel / Cloudflare Pages
